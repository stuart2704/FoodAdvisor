Make a new social automation token

Generated on this device using your browser's secure random-number generator. This page makes no network requests and does not store the token. Close the page to clear it.

  1. Generate and copy the token. Keep a private copy until you have saved it in both places. Do not paste it into chat.
  2. In Replit, add a secret named SOCIAL_AUTOMATION_TOKEN with this value.
  3. In the FoodAdvisor GitHub Actions secrets, add a repository secret with the same name and value.

Leave the GitHub scheduler disabled for now. Tell the agent “both saved” once you've finished; never send the token itself.
